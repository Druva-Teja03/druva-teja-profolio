# Druva's Dev Journey

CONTEXT

I am Druva Teja C, a 1st-year B.Tech Computer Science and Engineering (CSE) student building an engaging, modern personal portfolio website to showcase my early journey, technical foundation, and future projects to recruiters, mentors, and peers.

OBJECTIVE

Build a fully responsive, sleek single-page portfolio web application in React with Tailwind CSS and Lucide icons that highlights my skills, provides links to my socials, and includes structured placeholders for upcoming academic and personal projects.

STYLE

Modern minimalist developer portfolio with a clean dark-mode aesthetic (slate/zinc background with subtle neon or cyan/indigo accent colors). Use glassmorphism card designs, subtle hover animations, and crisp typography.

TONE

Professional, enthusiastic, ambitious, and clean.

AUDIENCE

Tech recruiters, internship coordinators, open-source maintainers, and fellow CSE students looking to collaborate.

RESPONSE / REQUIREMENTS

Header / Navigation:

Sticky navbar with smooth scroll links to: About, Skills, Projects, Education, and Contact.

Quick action buttons linking to:

GitHub: https://github.com/Druva-Teja03

LinkedIn: https://www.linkedin.com/in/druva-teja-c

Hero Section:

Large heading: "Hi, I'm Druva Teja C"

Subtitle/Badge: "1st Year B.Tech CSE Student | Aspiring Software Engineer"

Brief elevator pitch highlighting eagerness to learn, build, and solve real-world problems.

Primary CTA button: "Explore Projects" & Secondary CTA: "Contact Me".

Skills Section:

Categorized card grid with corresponding icons:

Languages: Python, HTML5, CSS3

Developer Tools: VS Code, Git, GitHub

Animated pill badges or progress chips with hover effects.

Projects Section (Showcase & Placeholders):

Grid layout featuring 3 card components with tags, GitHub repo link buttons, and live demo placeholders:

Card 1: Beginner Python Automation / CLI Tool

Card 2: Responsive Frontend Web Page (HTML/CSS)

Card 3: "Currently Building..." (Placeholder card highlighting work in progress)

Education & Timeline:

B.Tech in Computer Science and Engineering (Year 1)

Bullet points for core foundational coursework (Data Structures basics, Problem Solving, Web Development basics).

Contact Section & Footer:

Interactive contact form (Name, Email, Message) with client-side validation.

Direct social link badges (GitHub & LinkedIn).

Clean copyright footer.
